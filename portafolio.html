My Projects

Project 1: Flor de Lis - Online Ordering System

A responsive web application developed for a local health food store to simplify the ordering process for both customers and the business owner. The website allows users to browse products organized into categories, add items to a shopping cart, review their order, and submit it directly through WhatsApp. The application automatically calculates the order total, collects the customer's name, and generates a pre-formatted WhatsApp message containing the complete order, making the purchasing process faster and more efficient while reducing manual work for the seller.

Project 2: FOCUS FLOW - Productivity Web App
